# 브랜드 리소스 제작·합성 가이드

## 아웃트로

아웃트로는 배경이 포함된 완성 이미지가 아니라 **투명 PNG 전경 리소스**로 제작한다. 16:9, 9:16, 4:5, 1:1은 각각 해당 해상도의 독립 PNG를 사용하며, 한 비율의 파일을 다른 비율로 강제 확대하거나 잘라 쓰지 않는다.

인트로·아웃트로·워터마크 선택과 위치·크기·배경 설정은 콘텐츠별 값이 아니라 **사용자 계정 공통 브랜드 설정**이다. 콘텐츠 선택 없이 저장할 수 있어야 하며 모든 콘텐츠의 스텝 4 미리보기와 최종 렌더가 같은 공통값을 읽는다.

합성 계층은 미리보기와 최종 영상에서 항상 아래 순서를 지킨다.

1. 마지막 장면의 샘플 이미지 또는 마지막 영상 프레임
2. 사용자가 선택한 흰색 또는 검정 배경 레이어와 알파값
3. 선택한 출력 비율의 투명 아웃트로 PNG

`배경 없음`은 2번 레이어를 생략한다. 흰색·검정 알파는 아웃트로 PNG 자체에 입히지 않고 샘플 이미지와 투명 PNG 사이에만 합성한다. 위치, 크기, 배경색, 알파값은 16:9·9:16·4:5·1:1 프로필별로 독립 저장한다.

### 파일 검증

- PNG가 RGBA 형식이며 실제로 알파값 0과 255를 모두 포함해야 한다.
- 로고, 문구, 연락처, URL은 투명 영역으로 손실되거나 잘리지 않아야 한다.
- 미리보기와 FFmpeg 최종 출력은 동일한 비율 파일과 동일한 합성 순서를 사용해야 한다.
- 브랜드 목록에는 하나의 논리 버전만 표시하고, 비율별 파일은 그 버전의 내부 구성원으로 관리한다.

현재 v4 규격:

- 16:9: `1920×1080`
- 9:16: `1080×1920`
- 4:5: `1080×1350`
- 1:1: `1080×1080`
