# ThinkCast 월 정기 상품 API 원가 추정

기준일: 2026-08-31
용도: 임시 가격 정책 검토용. 공급자·모델·환율·재시도율에 따라 실제 원가는 달라진다.

## 상품 기준

- 주 1편, 월 4편 제작 및 배포
- 편당 이미지 생성 호출 20장(이미지 생성 로스 포함)
- 이미지마다 3~5초 이미지-투-비디오 생성
- 영상 생성 실패·재시도 여유 20%
- 음성은 영상 모델의 네이티브 오디오가 아닌 별도 TTS로 합성
- 배포 플랫폼 API는 유료 호출비가 없는 기본 쿼터 범위로 가정

## 기준 API

| 항목 | 기준 모델 | 공식 단가 | 편당 사용량 |
| --- | --- | ---: | ---: |
| 기획·대본·QA | 경량 텍스트/비전 모델 | 사용량 추정 | $0.15 예산 |
| 이미지 | Gemini 3.1 Flash Image (Nano Banana 2), 2K | $0.101/장 | 20장 |
| 이미지→영상 | Kling 2.5 Turbo, 720p, 무음 | $0.042/초 | 60~100초 × 재시도 1.2 |
| 음성 | Gemini 2.5 Flash TTS | $10/1M audio tokens, 25 tokens/초 | 60~100초 |

공식 가격 출처:

- Gemini API: https://ai.google.dev/gemini-api/docs/pricing
- Kling API: https://kling.ai/document-api/productBilling/billingMethod
- OpenAI 대체 이미지 모델: https://developers.openai.com/api/docs/models/gpt-image-1.5

## 판매가 상태

판매가는 아직 산정 중이다. 한 가지 저비용 조합만으로 판매가를 정하지 않고, 대본 LLM·이미지·I2V 공급자별 매트릭스와 사람 검수·인프라 비용을 검토한 뒤 확정한다.

## 제외 비용

- 사람의 기획·검수·수정 시간
- 고객별 추가 수정과 영상 재생성
- 유료 음원·폰트·스톡 자산
- 프로덕션 서버, 데이터베이스, 객체 저장소 및 전송량
- PG 수수료와 세금
- 플랫폼 광고비와 유료 부스팅
- 공급자 최소 충전액·선불 패키지·지역별 세금

실제 워커를 연결한 뒤에는 각 결과의 `metrics.cost`를 저장하고 최근 30일의 편당 P50/P90 원가로 가격을 다시 검토한다.
