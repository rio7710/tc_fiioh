# 테이블 형태 자동복구 패치 검증 결과

2026-10-19. 테이블 형태 충돌에 대한 제한된 보정과 코드 기반 신규 프로젝트 복구 분류를 배포했다. 실제 GPT를 사용한 합성 오류 보정은 3회 모두 한 번의 보정 요청으로 통과했다. 이 결과는 최종 영상·캘린더 전체 E2E 성공 3회를 의미하지 않는다.

## 이전 배치 결과와 원인

- 3개 목표 배치는 첫 콘텐츠의 최종 영상과 캘린더 3개 채널 등록까지 성공했다. 소요시간은 1,314초였다.
- 두 번째 콘텐츠는 318.2초 후 테이블 형태 검증에서 실패했다. 세 번째는 시작되지 않았다.
- 실패 프로젝트 `859dc935-b6e8-48e3-96a7-cb02119eb5c7`의 로그는 보정 횟수 0·1·2·3에서 동일 오류를 보여준다. 오류에 씬 ID와 필드 정보가 없어 전체 문서 보정으로 넘어갔다.
- 구형 자동복구 분류는 메시지의 ‘레퍼런스’를 중단 대상으로 취급했다. 따라서 보정 소진 후 신규 프로젝트 복구도 실행되지 않았다.
- 패치 시작 및 배포 직전 실행 중 자동제작·대본 작업은 0건이었다. 실패 로그와 기존 레퍼런스·콘텐츠는 보존했다.

## 변경 내용

- `TABLE_GEOMETRY_CONFLICT`: 씬 ID, 대상 props 인덱스, 현재 씬 이미지 프롬프트 경로, 기준 형태와 작성 형태를 기록한다.
- 전용 모듈은 위 경로의 텍스트만 변경한다. 레퍼런스 자산, 내레이션, 자막, 시간, 다른 장소의 소품은 변경하지 않는다.
- 보정 후 전체 문서 검증을 통과해야 채택한다. 실패하면 원본을 유지하고 거절 사유를 기록한다.
- 다른 장소를 명시한 소품 항목을 현재 장소의 전역 형태 규칙으로 사용하는 fallback을 제거했다. 실제 기존 실패가 이 오탐이었는지는 후보 원문이 완전히 남아 있지 않아 확정하지 않는다.
- 확인된 테이블 충돌은 구조화 코드로 복구 대상으로 분류한다. 자산 파일 누락·인증 등 중단 조건과 기존 보정 3회/신규 프로젝트 최대 2회 한도는 유지한다.
